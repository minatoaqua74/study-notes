BJT 與放大電路

電子學

BE 順偏、BC 逆偏，BJT 才能放大；三種組態各有特性。

BJT 構造與偏壓

雙極性接面電晶體（Bipolar Junction Transistor, BJT）由 P 型與 N 型半導體相接而成，有 NPN 與 PNP 兩種，是三端元件：基極（Base, B）在中間，另外兩端是集極（Collector, C）和射極（Emitter, E）。

基極－射極接合要加順向偏壓，基極－集極接合要加逆向偏壓，電晶體才能發揮放大等功能。

三種組態

三個端點都可以當作共同的參考點，因此有三種連接法：

組態共同端電流增益重點
共基極（CB）基極α = hFB = IC / IE輸入電流為 IE，輸出電流為 IC
共射極（CE）射極β = hFE最廣泛使用的組態
共集極（CC）集極—又稱射極隨耦器，電流增益最大

α 與 β 的關係

交流電流增益定義為 hfe = β = ΔIC / ΔIB（VCE 固定）。兩種增益可以互相換算：

h_fb = h_fe / (1 + h_fe)
h_fe = h_fb / (1 − h_fb)

放大與工作點

放大（Amplification）是讓輸入信號的振幅變大。要靠直流偏壓設定適當的工作點（Operating Point），信號才會在直流準位上下對稱變化。

轉移曲線的非線性區不能用來放大，否則輸出會失真。分壓器偏壓（四個電阻）的目的，是讓輸出直流電壓約為 VCC 的一半，使交流輸出有最大的擺動空間，且不會碰到 0 V 或 VCC。

三種放大器的交流特性

放大器輸出取自講義列出的特性
共射極（CE） 集極 輸出與輸入相位差 180°；功率增益 Gp = |Gv|·|Gi|
共集極（CC） 射極 Gv ≅ 1；Zout ≅ RE // re；Gi ≅ Zin / RL
共基極（CB） 集極 Zin = RE // re；Zout ≅ RC；Gv ≅ RC / re；Gi ≅ hFE / (1 + hFE) ≅ 1
待確認：講義的 CE 放大器完整交流特性（Zin、Zout、Gv 等）只有例題數字，未整理成通用公式，請對照課本。講義第 44 頁「三種放大器組態之摘要」只有一句提示，沒有摘要表。
易錯點／考點
  • 放大的偏壓條件是 BE 順偏、BC 逆偏，兩個接合不要記反。
  • CE 放大器的輸出與輸入反相 180°。
  • CC 的電壓增益約為 1，但電流增益大；CB 的電流增益約為 1，但電壓增益可以很大。
  • α = IC / IE 用於 CB，β 用於 CE，換算時要用上面兩條公式。

小測驗

共基極組態的直流電流增益 α 如何定義？

α = hFB = IC / IE。

射極隨耦器是哪一種組態？它的電壓增益約是多少？

共集極（CC）放大器，電壓增益 Gv ≅ 1。

若 hfe = 99，則 hfb 是多少？

hfb = hfe / (1 + hfe) = 99 / 100 = 0.99。
