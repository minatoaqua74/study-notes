Unix 基本操作

Unix

建使用者、給 sudo、開 ssh、分割磁碟並寫進 fstab 自動掛載。

使用者管理

Debian／Ubuntu 系可用 adduser（互動式、自動建家目錄）或 useradd（較底層，需自己加參數）。

sudo adduser ted
sudo useradd -m -s /bin/bash james   # -m 建家目錄
sudo passwd james                    # 設定密碼
id james                             # 查看 uid、gid、所屬群組

帳號資料在 /etc/passwd，密碼雜湊在 /etc/shadow。

sudo 權限

Ubuntu 系預設 sudo 群組的成員可使用 sudo。把使用者加入群組：

sudo usermod -aG sudo ted

要細部設定規則時，用 sudo visudo 編輯 /etc/sudoers，不要直接用一般編輯器改。

ssh 遠端登入

sudo apt install openssh-server
sudo systemctl status ssh
ssh ted@<主機 IP>

磁碟分割與自動掛載

  1. lsblk 找到新磁碟（例如 /dev/sdb）
  2. sudo fdisk /dev/sdb 建分割區，最後按 w 才會寫入
  3. sudo mkfs.ext4 /dev/sdb1 格式化
  4. sudo mkdir /mnt/data1 建掛載點
  5. sudo blkid 取得分割區 UUID
  6. 在 /etc/fstab 新增一行，再用 sudo mount -a 測試
UUID=<你的 UUID>  /mnt/data1  ext4  defaults  0  2
實際考試的帳號名稱、磁碟容量與掛載點以考題為準，此頁僅整理通用流程。
易錯點／考點
  • useradd 不加 -m 不會建立家目錄。
  • usermod -G 沒加 -a 會覆蓋原有群組，應使用 -aG。
  • fdisk 在按 w 之前都只是暫存，沒寫入就離開等於沒分割。
  • /etc/fstab 寫錯可能導致開機失敗，修改後務必先跑 mount -a 測試。

小測驗

如何把使用者 ted 加入 sudo 群組而不影響他原有的其他群組？

sudo usermod -aG sudo ted，關鍵是 -a（append）。

分割並格式化完成後，要讓系統開機自動掛載，需要修改哪個檔案？

/etc/fstab，建議使用 UUID 指定裝置，並用 mount -a 驗證。

要查看某個使用者所屬的群組，可用哪個指令？

id <使用者> 或 groups <使用者>。
