網路五層架構

網路通訊概論

五層各司其職，資料往下傳時每層加上自己的標頭。

五層與代表協定

層職責代表協定／設備資料單位
應用層（Application）提供應用程式的網路服務HTTP、SMTP、DNS訊息（message）
傳輸層（Transport）程序對程序的資料傳送TCP、UDP區段（segment）
網路層（Network）主機對主機的定址與路由IP、路由器資料包（datagram）
連結層（Link）相鄰節點間的傳送Ethernet、Wi-Fi、交換器訊框（frame）
實體層（Physical）在媒介上傳送位元線纜、無線訊號位元（bit）

封裝（Encapsulation）

傳送端由上往下，每一層在資料前加上自己的標頭（連結層另有尾部）；接收端由下往上，逐層拆掉標頭。

TCP 與 UDP

  • TCP：連線導向，提供可靠傳輸、流量控制與壅塞控制。
  • UDP：無連線，不保證送達與順序，但開銷小、延遲低。
易錯點／考點
  • IP 位址識別主機，port 號識別主機上的程序，兩者不同層。
  • 路由器主要運作在網路層，交換器主要運作在連結層。
  • 各層的資料單位名稱不同，不要全部都叫「封包」。

小測驗

HTTP 與 DNS 屬於哪一層？

應用層。

傳輸層的資料單位叫什麼？

區段（segment）。

哪一層負責把資料包從來源主機經路由送到目的主機？

網路層，由 IP 協定與路由器完成。
